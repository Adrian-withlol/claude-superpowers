# Superpowers for Claude Code

Add [Superpowers](https://github.com/obra/superpowers) to Claude Code with two commands. Superpowers gives Claude proven working habits: test-driven development, systematic debugging, planning before coding, and code review.

## Install

Type these into Claude Code:

```
/plugin marketplace add Adrian-withlol/claude-superpowers
/plugin install superpowers@avela-superpowers
```

Then restart Claude Code.

Or from a terminal:

```
claude plugin marketplace add Adrian-withlol/claude-superpowers
claude plugin install superpowers@avela-superpowers
```

## Update

```
/plugin marketplace update avela-superpowers
```

This repo points straight at the original Superpowers repository, so every install gets the latest version. No code is copied here.

## Remove

```
/plugin uninstall superpowers@avela-superpowers
/plugin marketplace remove avela-superpowers
```
